# Wendy Logan | Portfolio

Personal portfolio website built with React, TypeScript, and Vite. Features a clean, monospace-themed design showcasing my skills, projects, and experience in IT and software development.

## Live Demo

[View Live Portfolio](https://wendylogan.github.io)

## Tech Stack

- **React** – UI library
- **TypeScript** – Type safety
- **Vite** – Build tool and dev server
- **CSS** – Custom styles with CSS variables

## Getting Started

### Prerequisites

- Node.js (v16 or later)
- npm or yarn

### Installation

Clone the repository
```bash
git clone https://github.com/wendylogan/wl-web-portfolio.git
```

Navigate to project directory
``` bash
cd wl-web-portfolio
```

Install dependencies
```bash
npm install
```

Start development server
```bash
npm run dev
```

Then visit http://localhost:5173 (default for Vite)

## Features

- Responsive Design – Optimized for desktop, tablet, and mobile

- Skills Filtering – Filter skills by category (Programming, IT Support, QA, Documentation, Customer Service)

- Projects Filtering – Filter projects by technology/language

- Show More/Less – Expandable skills and projects lists

- Dark Theme – Monospace, terminal-inspired design
